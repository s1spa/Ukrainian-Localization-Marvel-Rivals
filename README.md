# Marvel Rivals - Українізатор

Неофіційний переклад тексту Marvel Rivals на українську мову. Повністю перекладено основний UI, меню, здібності героїв, магазин, події, бойовий пропуск тощо (~60 700 рядків локалізації).

## Статус

- Переклад: готовий, актуальний під версію гри Season 9.5 (`5.3.2-3761137+++depot_marvel+S9.5_release`).
- Джерело істини перекладу: [`Game_uk_merged_v2.json`](Game_uk_merged_v2.json) - `namespace -> {key: переклад}`.

## Як це працює (коротко)

Гра зберігає весь текст в одному файлі `Marvel/Content/Localization/Game/en/Game.locres` (компільований бінарний UE-локрес). Мод - це `.pak`-архів, який **оверрайдить** цей файл своєю перекладеною версією через стандартний механізм пріоритету завантаження UE (файл з найвищим числовим префіксом у назві мониться останнім і перекриває решту).

Пайплайн:

1. **Екстракція оригіналу** - через [FModel](https://fmodel.app/) з режимом завантаження **"All"** (обов'язково - окремий `pakchunkLocres-Windows.pak` застарілий і неповний, актуальний текст розкиданий по всіх архівах гри). Експортується `Game.locres` (сирий бінарник) і `Game.json` (той самий вміст у зручному JSON, namespace -> key -> текст).
2. **Переклад** - `0-translate_rivals.py`: перекладає відсутні/нові ключі через Gemini API (`gemini-flash-lite-latest` - вищий безкоштовний ліміт запитів/день, ніж у звичайного flash) з фолбеком на DeepL/Google Translate, з захистом плейсхолдерів (`{Name}`) і UE-richtext тегів (`<Tag>...</>`, включно з атрибутами типу `id="..."`). Результат мерджиться в `Game_uk_merged_v2.json`.
3. **Ручна вичитка** - велика частина якості перекладу - це вручну знайдені й виправлені помилки машинного перекладу (неправильний контекст, задовгий текст, що вилазить за межі UI, тощо). Список конкретних правок - у [`CHANGELOG.md`](CHANGELOG.md).
4. **Збірка `.locres`** - конвертація `Game_uk_merged_v2.json` у CSV (`key,source,target`, роздільник ключа `namespace/key`) і виклик [`UnrealLocres.exe`](https://github.com/akintos/UnrealLocres) (`import` режим - патчить оригінальний `Game.locres`, зберігаючи всі внутрішні метадані, замість генерації файлу з нуля).
5. **Пакування** - `repak_cli` (з набору [repak-rivals](https://github.com/natimerry/repak-rivals)) пакує `Game.locres` **разом з недоторканим оригінальним `Game.json`** (обов'язкова умова - без нього щось у грі ламається, причина невідома) у legacy-формат `.pak` (НЕ IoStore - `pakchunkLocres` в оригіналі теж legacy).

Детальніше про кожен крок і скрипт - на [GitHub Wiki](../../wiki).

### Чи підійде цей пайплайн для іншої гри?

Кроки 1-4 (екстракція, переклад, вичитка, збірка `.locres`) універсальні для **будь-якої гри на Unreal Engine**, що використовує стандартний формат локалізації `.locres` - це майже всі UE4/UE5 ігри, не тільки Marvel Rivals. Скрипти перекладу можна переносити майже без змін.

А от крок 5 (пакування й встановлення мода в гру) - **гра-специфічний**. AES-ключ шифрування, формат pak-архіву (legacy чи IoStore), наявність і спосіб обходу античиту/антитампера - усе це унікальне для кожної гри, і для нової гри цей крок доведеться проходити заново (зазвичай через пошук у моддерській Discord-спільноті саме тієї гри).

## Структура репозиторію

```
Game.json               - оригінальний англійський текст (namespace -> key -> текст), НЕ чіпати
Game.locres             - оригінальний англійський .locres (бінарник), база для патчингу
Game_uk_merged_v2.json  - переклад (джерело істини), редагувати тут
0-mergeloc.py           - мержить старий CSV-переклад з новим Game.json (у разі виходу нової версії гри з новими ключами)
0-translate_rivals.py   - авто-переклад відсутніх ключів через Gemini або DeepL
0-Fill_translation.py   - допоміжний скрипт заповнення CSV з JSON
0-bruh.py               - фільтр CSV (залишає тільки латиницю/кирилицю, ще з ранньої стадії роботи з сирим UEExtractor-дампом)
```

Не в репозиторії (застосунки сторонніх авторів, качати окремо):
- [FModel](https://fmodel.app/) - екстракція `Game.locres`/`Game.json` з гри
- [UnrealLocres](https://github.com/akintos/UnrealLocres) - патчинг `.locres` з CSV
- [repak-rivals](https://github.com/natimerry/repak-rivals) (`repak_cli`, `repak-gui`, `retoc-rivals-cli`) - пакування/встановлення модів під цю гру специфічно
- AES-ключ гри (публічний, спільнота моддерів): `0C263D8C22DCB085894899C3A3796383E9BF9DE0CBFB08C9BF2DEF2E84F29D74`

## Встановлення (для гравців)

Гра має захист від непідписаних модів (з квітня 2025). Щоб завантажити будь-який `.pak`-мод (не тільки цей), **обов'язково** потрібно встановити [UTOC Signature Bypass Patch for Marvel Rivals](https://www.nexusmods.com/marvelrivals/mods/2940) (дуже поширений, обов'язковий пререквізит для 2000+ модів цієї гри) - без нього мод просто не завантажиться.

Розпакуй його в `MarvelRivals\MarvelGame\Marvel\Binaries\Win64\` (поруч з `Marvel-Win64-Shipping.exe`).

Далі:
1. Постав мову клієнта на **English** у налаштуваннях гри (мод оверрайдить саме англійську локаль).
2. Поклади готовий `.pak` у `MarvelGame\Marvel\Content\Paks\~mods\`.
3. Назва файлу **обов'язково** має закінчуватись на `_P.pak` (інакше гра його не побачить).
